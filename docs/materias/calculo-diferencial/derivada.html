La derivada

El límite del cociente incremental

cálculo diferencial
derivadas
Definición de la derivada como límite del cociente incremental y su lectura geométrica como pendiente de la recta tangente.
Fecha de publicación

12 de septiembre de 2026

Tema 3 · 12 sep 2026

La derivada mide cuánto cambia una función cuando su entrada cambia poquísimo. Formalmente es el límite de la pendiente de las rectas secantes cuando los dos puntos se juntan.

Definición 3.1

\[ f'(a) \;=\; \lim_{h \to 0} \frac{f(a+h) - f(a)}{h} \]

cuando el límite existe. Si existe, decimos que \(f\) es derivable en \(a\).

Interpretación geométrica

La secante por \((a, f(a))\) y \((a+h, f(a+h))\) tiene pendiente igual al cociente incremental. Al hacer \(h \to 0\) esa recta se acuesta sobre la curva: la tangente.

R · secantes que se acercan a la tangente
library(plotly)

f <- function(x) x^2
a <- 1
x <- seq(-0.5, 2.8, length.out = 200)

p <- plot_ly() |>
  add_lines(x = x, y = f(x), name = "f(x) = x²",
            line = list(color = "#1f4e79", width = 3))

for (h in c(1, .5, .1)) {
  m <- (f(a + h) - f(a)) / h
  p <- add_lines(p, x = x, y = f(a) + m * (x - a),
                 name = sprintf("h = %.2f → pendiente %.2f", h, m),
                 line = list(dash = "dot", width = 1.5))
}

p |>
  add_lines(x = x, y = f(a) + 2 * (x - a), name = "tangente (h → 0)",
            line = list(color = "#0f766e", width = 2.5)) |>
  add_markers(x = a, y = f(a), name = "(a, f(a))",
              marker = list(size = 9, color = "#17181a")) |>
  layout(hovermode = "x unified",
         xaxis = list(title = "x"), yaxis = list(title = "f(x)"))

Derivabilidad implica continuidad

Teorema 3.2

Si \(f\) es derivable en \(a\), entonces \(f\) es continua en \(a\).

Demostración. Para \(x \neq a\) escribimos

\[ f(x) - f(a) = \frac{f(x) - f(a)}{x - a} \cdot (x - a). \]

Tomando límite cuando \(x \to a\), el primer factor tiende a \(f'(a)\) y el segundo a \(0\), así que \(\lim_{x \to a} f(x) = f(a)\). \(\blacksquare\)

El recíproco es falso: \(f(x) = |x|\) es continua en \(0\) pero no derivable ahí, porque los límites laterales del cociente incremental valen \(-1\) y \(1\).
